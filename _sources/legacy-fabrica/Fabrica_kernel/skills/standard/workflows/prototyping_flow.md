# Standard Workflow: Prototyping Flow

## Overview
The Prototyping Flow provides a structured yet lightweight environment for rapid experimentation, proof-of-concept building, and interactive client tool creation. It allows iterative exploration without requiring formal production scaffolding until a concept is validated.

## 1. Scope & Intent
Use Prototyping Flow when:
- Testing a new UI interaction model or layout pattern.
- Experimenting with a lightweight client-side utility or calculation engine.
- Validating a data transformation script or API payload parser.

## 2. Prototyping Guidelines
1. **Isolated Sandbox**:
   - Create prototypes in modular, self-contained components or standalone test scripts.
   - Avoid modifying production routes or core database schemas during initial prototyping.
2. **Rapid Iteration Cycle**:
   - Build functionally working prototype first.
   - Evaluate against user requirements and iterate immediately on visual or logic feedback.
3. **Promotion to Production**:
   - Once validated, extract clean reusable code from the prototype.
   - Refactor into standard architectural components and integrate into the main codebase.
