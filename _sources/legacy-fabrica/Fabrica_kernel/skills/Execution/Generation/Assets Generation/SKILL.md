# Sub-Skill: Assets Generation

## 1. Overview & Universal Context
This sub-skill operates under **Execution/Generation**. It handles graphic asset creation, UI/UX component design, vector illustrations, brand elements, and document design templates, saving outputs under **Deliverables / Executions**.

## 2. Operational Rules & Subroutines
1. **Spec Ingestion**: Ingest visual requirements from Strategic Synthesis or Discovery scoping.
2. **Asset Generation**: Produce clean visual assets, SVG vector graphics, design system tokens, or styled document layouts.
3. **Registration**: Store outputs in **Deliverables / Executions**.

## 3. Sub-Domain Modules
- `./domains/design_templates.md` (UI/UX templates, SVG vectors, graphic components)
