# Component Synthesis Protocol

## What
Rules for synthesizing responsive, accessible, high-contrast UI components and layout views.

## Rules
1. **Responsive Design**: Ensure mobile viewport compatibility (`sm:`, `md:`, `lg:`) while maintaining desktop layout integrity.
2. **Interactive Controls**: Wire up complete event handlers without leaving mock or silent click stubs.
3. **Typography & Spacing**: Maintain mathematical spacing rhythm and high contrast legibility.
4. **Theme Alignment**: Adhere to established CSS variable tokens for colors, borders, and dark/light modes.
