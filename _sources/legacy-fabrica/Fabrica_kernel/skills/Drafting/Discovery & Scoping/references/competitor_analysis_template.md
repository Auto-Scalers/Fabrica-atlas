# Competitor Analysis Template

## What
A structured template for analyzing competing products or reference systems during brainstorming precedents research.

## When
Used by `precedents_research.md` when the brainstorming subject involves a market with existing solutions worth analyzing.

## Template

```json
{
  "competitor_name": "",
  "url": "",
  "category": "",
  "strengths": [],
  "weaknesses": [],
  "key_ui_patterns": [],
  "key_features": [],
  "pricing_model": "",
  "target_audience": "",
  "differentiation_opportunity": ""
}
```

## Evaluation Criteria
1. **UI Patterns**: What layout, navigation, and interaction patterns do they use?
2. **Strengths**: What do they do demonstrably better than alternatives?
3. **Weaknesses**: What do users complain about (check reviews, forums, G2)?
4. **Differentiation**: What specific gap does Fabrica exploit that this competitor misses?
