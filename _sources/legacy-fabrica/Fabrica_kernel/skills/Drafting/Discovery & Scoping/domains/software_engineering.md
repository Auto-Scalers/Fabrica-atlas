# Discovery Sub-Domain: Software Engineering

## Subroutines
1. **Tech Stack Evaluation**: Compare framework choices (e.g. Next.js vs Vite, Express vs Fastify) with pros/cons, performance overhead, and maintenance effort.
2. **Architecture Boundary Mapping**: Define core modules, API endpoints, database models, and service boundaries.
3. **Trade-off Analysis**: Present build vs buy options, monorepo vs microservices trade-offs, and scaling bottlenecks.
