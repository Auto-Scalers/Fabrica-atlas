# Discovery Sub-Domain: System Automation

## Subroutines
1. **Trigger & Webhook Identification**: Map event sources (HTTP endpoints, database webhooks, scheduled cron jobs).
2. **Integration Node Mapping**: Identify external service connectors (e.g. Slack, Gmail, Stripe, GitHub, Supabase).
3. **Retry & Error Handling Scoping**: Define failure recovery rules, rate limiting constraints, and notification channels.
