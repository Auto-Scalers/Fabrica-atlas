# Discovery Sub-Domain: Data Analytics

## Subroutines
1. **Data Source Identification**: Identify raw CSVs, SQL databases, API telemetry logs, and third-party data providers.
2. **Key Metric Formulation**: Define primary KPIs, aggregated dimensions, and analytical query requirements.
3. **Ingestion & ETL Scoping**: Map data freshness requirements, batch vs streaming pipelines, and schema validation constraints.
