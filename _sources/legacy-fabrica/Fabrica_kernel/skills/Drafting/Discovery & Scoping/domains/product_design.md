# Discovery Sub-Domain: Product Design & UX

## Subroutines
1. **User Persona & Journey Mapping**: Define target user profiles, primary workflows, and key interaction touchpoints.
2. **Interface Hierarchy**: Scope layout views, navigation structure, dashboard panels, and mobile responsiveness.
3. **Design System Constraints**: Determine color tokens, typography scales, component library usage (e.g. Tailwind, shadcn/ui).
