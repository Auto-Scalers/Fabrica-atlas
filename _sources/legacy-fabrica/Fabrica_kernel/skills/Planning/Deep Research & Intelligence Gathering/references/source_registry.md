# Source Registry

## What
Curated registry of authoritative, official documentation sources per technology domain. Used by `official_source_query.md` to identify where to retrieve documentation.

## When
Referenced at the start of every official source query to locate the correct authoritative URL before any search begins.

## Why
Going to the wrong source wastes time and risks retrieving outdated or incorrect information. This registry maps domains to their definitive documentation homes.
