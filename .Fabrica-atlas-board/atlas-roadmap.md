# Fabrica Transformation Roadmap

> **First batch = the rebrand look + unfair-advantage features.** Detailed plans for each item live in its own folder under `plans/`.
> Lower-level reference (what Fabrica already has, MC/buzz parallels, new ideas) lives in `systems.md` and `ideas.md` — the roadmap does not repeat those details.

## Batch 1 — Rebrand Look + Unfair Advantage

| # | Feature | Plan folder |
|---|---|---|
| 1 | **Default "Orcastration" project** — ships with default orcastration terminals: one orcastration terminal per project + a meta-orcastrator that orcastrates those orcastrators. | `plans/01-default-orcastration-project/` |
| 2 | **Unified chat UI (top layer)** — a unified chat layer that sits above the terminal, across all agents. | `plans/02-unified-chat-ui-layer/` |
| 3 | **Role + type assignment (agent personas)** — option on terminals to assign a role/persona and a type: `Meta-ORCH`, `Orcastrator`, `Worker`. | `plans/03-role-persona-and-type-assignment/` |
| 4 | **Enhance orchestration + communications + tasks systems** — improvements to the existing orchestration, communications, and tasks systems. | `plans/04-enhance-orch-comm-tasks/` |
